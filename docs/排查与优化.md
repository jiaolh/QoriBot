# 本次连接排查、内存检查与长期记忆

检查日期：2026-10-05。程序、资料、运行环境和测试工具均保存在 QQBot 文件夹中。

## 连接失败的原因与修复

原后台进程是从 Codex 的受限执行环境启动的，联网请求立即返回 `EACCES`。Windows 的启动入口检测到本地服务已存在后，复用了这个受限进程。这里需要修正的是启动环境，不是给防火墙添加一条规则。

遇到类似错误时，先从正常 Windows 终端或启动入口运行，再检查官方鉴权、网关查询与 WebSocket 连接。模型对话则独立检查所选 API 的网络和凭证配置，无需因此直接修改防火墙。

以后在 Windows 文件夹双击 start.cmd 启动。若看到 EACCES，先在界面“退出程序”，再正常启动。新的页面会显示具体错误；连接失败后等待五秒重试，连接期间不创建第二个机器人实例。首次连接超过 30 秒会停止该次尝试并提示检查网络。

## 内存验证及边界

采用两种本地模拟检查，使用虚拟凭证，不给 QQ 用户发送消息：

| 检查 | 结果 |
|---|---|
| 3000 次失败连接，6 批，每批 500 次后垃圾回收 | 历史机器人实例残留 0；活动资源仅为测试输出管道，没有遗留连接定时器 |
| 失败压力测试堆内存 | 500 次 9.30 MB，1500 次 9.36 MB，3000 次 9.44 MB，预热后增长很小 |
| 失败压力测试进程总内存 RSS | 71.69 MB → 87.75 MB，后两批趋稳，属于已观察到的运行时分配保留 |
| 50 次正常连接、停止 | 网关连接、心跳、重连计时器、事件监听器、消息去重及冷却缓存全部关闭或清空 |
| 实际 QQ 已连接时 | 服务约 62–70 MB，堆约 11–12 MB，浏览器内存另计；具体数值随负载变化 |

这些结果没有发现连接重试造成的对象或定时器持续残留。压力测试不是对所有长期负载都不存在泄漏的保证；RSS 上升也不能单独作为泄漏证据。界面现在同时显示总内存和堆内存，便于观察。

复查命令（项目根目录）：

```powershell
.\runtime\node\node.exe --expose-gc scripts/verify-lifecycle.js
.\runtime\node\node.exe --test
.\runtime\node\node.exe scripts/diagnose-network.js --qq-auth
```

前两项使用本地模拟服务。第三项访问 QQ 官方域名，用已保存凭证验证鉴权和网关，不显示密钥或 Token，不发送聊天消息；请在正常 Windows 终端运行。

## 已完成的优化

- 连接失败和停止时清空 Token 缓存、监听器、去重和冷却缓存，释放旧机器人引用。
- 连续点击保护、五秒重试间隔、30 秒启动超时；界面显示联网环境、DNS、超时和鉴权错误。
- 状态请求去重；未变化的日志、记忆列表和空间条不再反复重建；后台页面暂停轮询。
- 固定环境与依赖目录只在首次或手动刷新时扫描；变化的数据目录每分钟更新。
- 长期资料按需读取，自动整理最多一个后台请求、16 项有界队列，并遵守总并发限制。停止程序会取消整理。
- 用户数或资料文件超限时，普通聊天可以继续，日志提示资料暂不可用。
- 页面资源加入内容版本，升级并重启后刷新页面即可取得新界面。

无需新增依赖，没有 Electron、向量数据库、常驻浏览器代理或前端构建服务。

## 用户记忆如何使用

“用户记忆”页面默认显示长期资料。每位用户记录偏好、身份背景、长期目标或重要事实，正文为 Markdown；同一聊天场景中跨提示词保留。近期对话是另一页，受轮数与过期限制。

| 操作 | 效果 |
|---|---|
| `/记住 我正在学习 Python` | 直接写入长期资料，不为整理额外调用模型 |
| `/记忆` | 查看当前场景中自己的长期资料 |
| `/reset` 或 `/重置` | 清空当前提示词的近期对话，长期资料保留 |
| `/忘记` | 清空长期资料并排除旧资料来源，近期原文仍保留；可另外清空近期对话 |
| 手动编辑资料 | 可改 Markdown、备注、启用及自动整理开关 |
| 关闭自动整理 | 仍使用已有资料；不再额外调用模型归纳 |
| 关闭使用长期资料 | 不注入资料，也不自动整理；保存的旧资料保留 |

文件在 `data/users/24位用户标识/memory.md`。QQ 标识由平台提供，不一定是 QQ 号。不同群、不同群成员、私聊和本机用户分别保存，避免串用个人资料。这里实现的是持久用户资料与自动归纳，不需要模型 API 提供专门的“记忆”功能。

自动整理有一定模型用量，且可能归纳不准确。关键资料可用 `/记住` 或手动编辑。自动整理失败、用户主动停止或旧任务遇到较新的手动修改时，保留已有内容。长期资料与当前问题会发送给你选用的模型 API，和普通对话采用同一服务。

旧版“试聊”故意不落盘，过去已经关闭的内容无法恢复。新版“本机对话”保存上下文和长期资料；QQ 用户需在对应 QQ 聊天中建立。完整备份含 settings.json、memory.sqlite 和 users 文件夹，迁移仍然只需退出后移动整个 QQBot 文件夹。
