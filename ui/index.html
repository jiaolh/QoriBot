目录与迁移

Windows x64
runtime/

内置 Node.js 与包管理工具，启动时优先使用。

node_modules/

已安装的官方 SDK；使用普通目录，无外部链接。

src/ · ui/ · plugins/

核心逻辑、公共界面和独立功能插件；无需前端构建。

data/

settings.json 保存配置与密钥；memory.sqlite 保存近期对话、资料索引和插件预约；users/ 保存长期 memory.md。

backups/ · .cache/

数据备份和安装缓存；可在上方按需清理。

scripts/ · test/

启动、依赖安装与自动测试；使用说明见 README.md。

迁移前先退出程序，再移动整个 QoriBot 文件夹。目标电脑需为 Windows x64；QQ 平台若启用 IP 白名单，需要更新公网出口 IP。系统浏览器和 Windows 本身不包含在文件夹内。
